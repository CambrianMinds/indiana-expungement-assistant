The Lifetime "One-Shot" Rule & Multi-County Trap

“A person may file a petition for expungement of a conviction record under this chapter only one (1) time during any period of the person's life.”
— Indiana Code § 35-38-9-9(i)
🎯

One Lifetime Opportunity

Unlike states with rolling expungement, Indiana law permits you to file for conviction expungement only once in your entire lifetime.

⏳

The 365-Day Consolidation Window

Under IC § 35-38-9-9(d), if you have convictions in multiple Indiana counties (e.g., Marion & Hamilton), all petitions must be filed within 365 days of the first.

🚫

Permanent Forfeiture

If you forget or neglect to include any conviction in your petition packet, you can NEVER expunge that omitted conviction for the rest of your life.

Architecture

How It Works: 100% Client-Side Privacy

Because Indiana's MyCase aggressively blocks cloud scraping bots, our browser extension scrapes in-session directly in your Chrome browser and communicates locally with your offline Python engine.

1

Navigate to MyCase

Log in or search your public record on mycase.in.gov. Open the Indiana Expungement Assistant side panel with one click.

2

1-Click Scraping

The extension's content script parses case details, charges, dispositions, and cause numbers from the Knockout.js DOM in real-time.

3

Local PDF Generation

Your local Python FastAPI engine compiles the scraped data into 10 court-ready PDF documents using official ReportLab formatting.

4

Print & File Pro Se

Download the unified ZIP packet, sign the verified petition under penalty of perjury, and submit to your County Clerk or E-File Indiana.

Getting Started

Quickstart Setup Guide

Get up and running in under 3 minutes. Clone the repository and load the extension in Chrome.

  • 1

    Clone the Repository

    Open your terminal and clone the repository locally:

    git clone https://github.com/CambrianMinds/indiana-expungement-assistant.git
  • 2

    Open Chrome Extensions Manager

    Navigate to chrome://extensions in Google Chrome and enable Developer mode (toggle in top right).

  • 3

    Load Unpacked Extension

    Click Load unpacked and select the extension/ folder from the repository. The assistant icon will appear in your Chrome toolbar.

  • 1

    Install Dependencies

    Navigate to the backend/ folder and install the required Python packages:

    cd indiana-expungement-assistant/backend
python -m venv .venv
# On Windows:
.\.venv\Scripts\activate
# On macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
  • 2

    Launch the Local Engine

    Run the FastAPI form generation server (runs on http://127.0.0.1:8000):

    python app.py
  • 3

    Verify System Health

    Open http://127.0.0.1:8000/health in your browser to confirm the engine is active.

The Creator's Mission & Purpose

Built by an independent individual advocating for legal accessibility

Indiana's Second Chance Law (IC § 35-38-9) is one of the most progressive expungement statutes in the nation—granting ordinary working people who have paid their debt to society a statutory right to clean their record and regain employment, housing, and civil dignity.

However, navigating Indiana's procedural rules, strict statutory waiting periods, and the unforgiving Lifetime One-Shot Rule is intentionally intimidating. Private attorneys routinely charge between $1,500 and $3,500 for routine misdemeanor expungements—putting this statutory right completely out of reach for the very people who need it most.

I built this software as an independent individual who believes that legal record clearing should be an accessible, dignified, self-service process. Technology should empower self-represented citizens to access justice, not lock them out.
