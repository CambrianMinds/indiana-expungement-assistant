⚠️ CRITICAL STATUTORY WARNING

Protecting Your Rights: The Once-In-a-Lifetime Expungement Rule

“A person may file a petition for expungement of a conviction record under this chapter only one (1) time during any period of the person's life.”
— Indiana Code § 35-38-9-9(i)

A Single Lifetime Proceeding

Unlike states with rolling expungement statutes, Indiana strictly limits conviction record expungement to a single proceeding in your lifetime.

The 365-Day Consolidation Window

Under IC § 35-38-9-9(d), if you have convictions across different Indiana counties (e.g. Marion & Hamilton), all petitions must be filed within 365 days of the first filing.

Permanent Forfeiture of Omitted Cases

If you neglect to include any conviction in your petition, you permanently forfeit the right to ever expunge that conviction for the remainder of your life.

How Everyday Hoosiers Prepare Their Expungement

By combining secure in-browser scraping with an offline local document generator, you maintain complete privacy while preparing court-ready documents.

1

Navigate to MyCase

Search your public court records on Indiana's official mycase.in.gov portal. Open the assistant side panel in Chrome.

2

1-Click Record Scan

The browser extension securely parses case cause numbers, charges, and dispositions directly within your active web session.

3

Local PDF Generation

Your local Python engine compiles the data into 10 official court pleadings adhering to Indiana Trial Rules—without sending PII to any cloud server.

4

Sign & File Pro Se

Download your complete court packet, sign the verified petition under penalty of perjury, and deliver to the County Clerk or submit via E-File Indiana.

User Guide

How to Install and Run the Assistant

This software is 100% free and open source. Follow these simple steps to install the Chrome extension and launch the local document generator.

  • 1

    Download or Clone the Repository

    Download the project ZIP from GitHub or clone the repository to your computer:

    git clone https://github.com/CambrianMinds/indiana-expungement-assistant.git
  • 2

    Open Chrome Extension Management

    In Google Chrome, navigate to chrome://extensions in the address bar and switch on Developer mode in the upper-right corner.

  • 3

    Load Unpacked Extension

    Click the Load unpacked button and select the extension/ folder inside the downloaded project. The scales icon will appear in your Chrome toolbar.

  • 1

    Set Up Local Python Environment

    Open your command terminal, navigate to the backend/ folder, and install the document generation libraries:

    cd indiana-expungement-assistant/backend
python -m venv .venv

# On Windows:
.\.venv\Scripts\activate

# On macOS or Linux:
source .venv/bin/activate

pip install -r requirements.txt
  • 2

    Start the Document Engine

    Launch the local microservice (runs privately on http://127.0.0.1:8000):

    python app.py
  • 3

    Verify System Status

    Visit http://127.0.0.1:8000/health in your web browser. You will see {"status":"healthy"} confirming your private engine is ready.

The Public Interest Mission

A message from the independent creator on legal accessibility

Indiana's Second Chance Law (Indiana Code § 35-38-9) is among the most meaningful civil reforms in the state's history. It recognizes a fundamental principle of justice: when individuals have paid their legal debt and demonstrated rehabilitated lives, an old criminal record should not remain a permanent barrier to gainful employment, safe housing, professional licensing, and civic participation.

Yet for tens of thousands of everyday working Hoosiers, this statutory right exists only on paper. Navigating court rules, formatting formal legal pleadings, and deciphering the unforgiving Lifetime One-Shot Rule is intentionally intimidating. Private criminal defense attorneys frequently charge between $1,500 and $3,500 for routine expungement petitions—creating an economic barrier that locks out the very citizens who need a clean slate the most.

I created this project as an independent individual who believes that legal document preparation under statutory second chance laws should be accessible, transparent, and free. Technology should open courtroom doors for self-represented citizens, not keep them shut.
